# DrumKey Decision Log

This file records confirmed product decisions, working assumptions, and unresolved questions. Update it whenever a decision changes or a question is resolved. When an area has several dated entries, the latest decision takes precedence; earlier entries preserve the project history.

## Confirmed decisions

| Date | Area | Decision | Reason or consequence |
| --- | --- | --- | --- |
| 2026-11-24 | Input behavior | D, F, J, K, L and Space retain their ordinary operating-system and application actions while DrumKey is enabled. | DrumKey remains usable alongside ordinary work. |
| 2026-11-24 | Overlay position | Start in the top-left of the selected display, then allow clicking and dragging anywhere on the overlay. | Supersedes the fixed position and mouse click-through behavior. The panel keeps keyboard focus in the working app. |
| 2026-11-24 | Remembered placement | Remember the dropped position separately for each display, relative to its usable area. | Placement survives app restarts and adapts to screen resolution changes. Drops are kept inside the usable screen bounds. |
| 2026-11-24 | Dragging between displays | Dropping the overlay on another display selects that display in Settings. | The new display and placement survive a restart. |
| 2026-11-24 | Display selection | Use the first secondary display when one is connected. Fall back to the main display when there is only one display. | Prefer moving the ambient visual away from the primary workspace. |
| 2026-11-24 | Visual character | Keep the time signature and soundstage tiny, light, and consistent with Apple’s Liquid Glass design direction. | The overlay should feel ambient and avoid obscuring work. |
| 2026-11-24 | Glass implementation | Use AppKit’s native `NSGlassEffectView` on macOS 26 and newer, with a system visual-effect material on older supported versions. | Native materials adapt to appearance and accessibility settings. |
| 2026-11-25 | Visual mapping | Alternate D/F across the six left-side columns and J/K across the six right-side columns, reading top to bottom. | Supersedes the three-column groups of one color and preserves the left/right hand mapping. |
| 2026-11-24 | Mapping meaning | Treat the visual mapping as expressive feedback rather than an accurate interpretation of the user’s intended instrument. | Key identity alone cannot reveal musical intent. |
| 2026-11-24 | Meter presentation | Always show a provisional time signature, starting at 4/4, and refine it during continued tapping. Mark uncertain estimates with the approximate symbol. | Supersedes the initial decision to withhold ambiguous meter. |
| 2026-11-24 | Accent input | Treat Space as an explicit downbeat or accent marker. | Space recurrence can contribute more strongly to bar and meter hypotheses. |
| 2026-11-24 | Idle appearance | Keep the overlay faintly visible whenever DrumKey is enabled. | The user can see that capture is active without waiting for a hit. |
| 2026-11-25 | Motion | Keep column bases fixed and grow only their tops, with gradual decay and additive retriggers from the remaining height. Remove spreading ripples. | Supersedes the translated eight-point lift and 180 ms return. Height scales with the circle, and Reduce Motion keeps columns stationary. |
| 2026-11-25 | Visual themes | Retain Glass Circle and add Pulse Halo, Radial Spectrum, Linear EQ, Mirror Wave, Orbit Dots and LED Matrix in a live Settings dropdown. | Six new compositions use the same key input and energy. Glass Circle remains the default. Research and theme details live in [THEMES.md](THEMES.md). |
| 2026-11-25 | Color schemes | Add an independent live dropdown for Classic, Aurora, Sunset, Neon, Ocean, Ember and Gunmetal. Remember both selectors. | Classic preserves the original colors. Other schemes recolor the main visualizer, background spectrum and border together. |
| 2026-11-27 | Expanded themes | Add Circle Towers, Razor Bloom, Silk Ribbons and Hex Array, bringing the selector to eleven themes. Refresh Orbit Dots as Orbit Shards while preserving its saved preference identifier. | The user requested more themes and a second circular tower layout. All options remain native drawings driven by the same hit envelopes. |
| 2026-11-27 | Expanded color schemes | Add Ultraviolet, Cyberpunk, Acid, Glacier, Rose Quartz, Copper, Jade and Monochrome, bringing the selector to fifteen palettes. | Each palette applies to the main layout, background spectrum and border feedback and is saved independently of the theme. |
| 2026-11-27 | Space bass response | Space triggers both D and F visually in every layout, the background EQ and the joint-bass border flash, while retaining its downbeat/rim accent. | Route one real Space hit into D/F/Space visual events at the original timestamp. Rhythm analysis receives the one original Space onset, and the listener keeps ordinary keyboard behavior. |
| 2026-11-27 | EQ bass placement | D/F columns always occupy the left half of Linear EQ and LED Matrix, with J/K/L on the right. The background EQ uses the same placement. | The user's follow-up explicitly fixes bass on the left. Linear EQ uses solid banks; LED Matrix uses paired D/F clusters followed by two J/K/L groups. |
| 2026-11-27 | EQ bass height | Give Linear EQ a 107-point bass peak versus 67 points for J/K/L at 1×; LED bass has sixteen rows versus ten. Cap background percussion energy at 0.64 versus 0.98 for bass. | For equal energy, bass has greater travel and a higher maximum. All foreground dimensions scale with the chosen overlay size. |
| 2026-11-24 | Generated sound | Do not generate drum sounds in any version of DrumKey. | DrumKey is a visual companion rather than a drum sampler. |
| 2026-11-24 | Minimum system | Support macOS 15 and newer. | A roughly two-year support window is acceptable and allows greater use of current platform behavior. |
| 2026-11-24 | Multiple secondary displays | Use the first secondary display reported by macOS by default. | This is acceptable without requiring initial configuration. |
| 2026-11-24 | Display settings | Include a Settings display picker. | Users can override automatic display selection and the preference survives a restart. |
| 2026-11-24 | MIDI | Do not work on MIDI support in the current project scope. Preserve it only as a possible later extension. | MIDI can be wired to the hit stream later if the product evolves in that direction. |
| 2026-11-24 | Saved display unavailable | Temporarily fall back to another available display when the chosen display disconnects, then automatically return when it reconnects. | The overlay remains available without discarding the user’s display preference. |

## Implementation choices

| Date | Area | Choice | Reason or consequence |
| --- | --- | --- | --- |
| 2026-11-25 | Overlay footprint | Start with a vertical 192 × 252 point HUD and a default 16 point inset from the usable top-left corner. Add saved 1×, 1.5×, 2× and 3× size settings. | The panel and circle enlarge together, with the requested size limited to the selected display's usable area. Dragging and per-display placement remain available. |
| 2026-11-25 | Text during resizing | Keep the meter at 22 points and BPM/status at 11 points while enlarging the panel and circle. Keep both labels centered at the top. | Text remains the same physical size at every preset. |
| 2026-11-24 | Soundstage scale | Use a 167.2 point circular stage, 10% wider than the previous 152 point stage. | The circular layout determines the new overlay width. |
| 2026-11-25 | Soundstage appearance | Arrange twelve alternating input columns and four wider L columns around an open center. | Three D, three F, three J and three K columns are separated by four cardinal L accents. |
| 2026-11-24 | Mirrored projection | Mirror the stage, glass faces, reflections and shading horizontally. | Reverses the previous apparent direction of the rising blocks. |
| 2026-11-25 | Bass emphasis | Make D/F columns 35% wider with stronger glass faces and thicker highlights. Keep width fixed during hits. | Preserves their bold appearance while the anchored top rises. |
| 2026-11-25 | Shared visual energy | Each key hit adds 0.42 to its current decayed energy, capped at 1.0. Release exponentially with a 0.70-second time constant. Glass tops extend up to 24 points at 1×. | Repeated hits build from the current position; bottom edges and widths stay fixed. Switching themes and palettes preserves the active envelope. |
| 2026-11-25 | Radial impact | Give Pulse Halo up to 36 points of outward travel at 1×, Radial Spectrum about 41 points, and Orbit Dots an outward bead kick with anchored stems and stronger highlights. | Use the same additive hit energy and 0.70-second release as Glass Circle. Peaks reserve space for glow and the fixed-size labels at every preset; Reduce Motion keeps the shapes stationary. |
| 2026-11-25 | Radial key regions | Use a shared mirrored sweep for Pulse Halo, Radial Spectrum and Orbit Dots: D broad upper crests, F outer upper shoulders, J sidewalls, K lower shoulders and L fine lower peaks. Space accents the complete rim. | Every hit remains balanced left to right. Smooth overlapping angular fields replace the inherited alternating glass columns and radial four-cardinal L cross. Glass Circle and flat layouts retain their established mappings. Placement rationale and primary research sources are in [THEMES.md](THEMES.md#radial-key-composition). |
| 2026-11-25 | Radial color and orbit composition | Blend key colors through the same mirrored fields. Give Pulse Halo a matching vertical glass gradient and use twenty Orbit Dots beads joined around the perimeter, with fuller bass beads and finer L accents. | Color supports the region hierarchy, while the halo and necklace leave the center open. Static field and color samples are cached outside animation frames. |
| 2026-11-27 | Radial composition revision | Replace the upper-to-lower band sweep: D drives broad lateral jaws, F four diagonal horns, J the top crown, K the lower crown and L twelve fine rim teeth. Use pointed Halo crests, seventy-two tapered spectrum spears, twenty-four Orbit Shards and faceted Razor Bloom blades. | The user disliked the previous regional mapping and requested pointed bass-distortion shapes. Compact angular fields produce sharp crests while retaining additive retriggers, gradual release, bounded travel and Reduce Motion. |
| 2026-11-27 | Circle Towers | Arrange eighteen glass pillars on a projected elliptical circle: D/F control the front-left/front-right banks, J/K the rear-left/rear-right banks and L two side beacons. | This gives the second circular tower layout its own assignments. Bases stay anchored; bass extends by 36 points, percussion 26 and L 44 at 1×. |
| 2026-11-27 | Other new layouts | Silk Ribbons uses five horizontal bands for D/F/J/K/L from top to bottom. Hex Array uses nineteen faceted cells with a D central spine, F middle flanks, J/K side cells and L edge tiles. | Provide distinct horizontal and geometric alternatives in the existing dropdown without adding new windows or sound. |
| 2026-11-25 | Manual accent preview | Include an L example alongside percussion in the Settings rhythm preview. | The preview demonstrates the lower radial accents; live L remains entirely manual and outside tempo and meter analysis. |
| 2026-11-25 | Theme implementation | Draw the six new layouts natively in AppKit with cached color palettes, existing size presets and Reduce Motion support. | The researched projects supply visual references; no external renderer, copied assets or audio input is introduced. Timers stop once energy settles. |
| 2026-11-25 | Joint bass border flash | Pressing D and F within 80 ms triggers a deep gunmetal blue (#213342) flare around the rounded border, fading within 360 ms. Consume each pair once and use original event timestamps. | Replaces the blue-violet flash. Holding keys does not generate a continuing strobe, and Reduce Motion uses a dimmer pulse. |
| 2026-11-25 | Accent placement | Place four 19-point-wide teal L columns at north, west, south and east at 1×. Scale their width with the circle. | These accents are wider than the bass and percussion columns and remain manual. |
| 2026-11-25 | Circle alignment | Center projected resting columns and circular rims on the same point at every size. | Compensates for the height and depth of the projected glass. |
| 2026-11-25 | Percussion border meters | J drives the left segmented border meter and K the right, while both still animate their circle columns. An isolated hit starts at 8% of panel height. | Border peaks build toward a hard cap of 60% height through sustained input rather than reaching the cap on every hit. |
| 2026-11-25 | Border buildup | Require 30 seconds of continued tapping and at least 60 hits in the latest 30 seconds on a lane to reach its 60% cap. A gap over three seconds restarts that lane's buildup. | Roughly two taps per second on a key for thirty seconds earns maximum height. A rapid short burst cannot skip the duration requirement. |
| 2026-11-25 | Border release | Each J/K border hit releases within 220 ms. Reset history on pause, reset, sleep or unavailable capture. | Sustained history controls peak height while individual rises stay crisp. Reduce Motion uses fixed-height tracks with brightness feedback. |
| 2026-11-24 | Manual accent bars | L triggers all four new bars together and keeps its normal typing behavior. | L is a visual control and does not alter BPM or meter estimates. |
| 2026-11-24 | Automatic accent bars | Remove automatic L-column triggering and its beat scheduler. Keep L as a manual accent control. | Supersedes the earlier learned-beat automation. The background EQ replaces its ambient motion. |
| 2026-11-24 | Background EQ | Draw forty 1.1 point spectrum stems behind the circle and text across the entire overlay. The same real key hits drive both visualizers. | D/F emphasize the left bands, J/K the right, L the high bands and Space the whole spectrum. The EQ is expressive key feedback. |
| 2026-11-24 | EQ transparency | Default to 92% transparency and provide an independent Settings slider from 0% to 100%. Persist the setting. | Higher values make the EQ fainter; 100% hides it. Overall overlay visibility remains separately adjustable. |
| 2026-11-25 | EQ palette | Classic uses green at the bottom, yellow and orange above, and red at the highest peaks. Other color schemes supply matching spectra. Anchor gradients to the full overlay height. | Strong combined or repeated hits can reach the top colors without making every short band end in them. |
| 2026-11-24 | EQ activity lifetime | Decay key-driven energy over 950 ms, then leave a faint static resting pattern and stop animation frames. Reset on pause, reset, sleep or unavailable capture. | Background motion follows actual tapping. Reduce Motion keeps the EQ stems stationary and varies their brightness. |
| 2026-11-24 | Space feedback | Light the complete circular rim for a Space accent. | The center stays open. |
| 2026-11-24 | Enable shortcut | Use Control + Option + Command + D as a global toggle when the shortcut is available. | DrumKey can be paused while another app is active. The menu remains available if registration fails. |
| 2026-11-24 | Shortcut input | Ignore key repeats and mapped keys held with Command, Control or Option. | Held keys produce one hit and normal keyboard shortcuts avoid adding accidental hits. |
| 2026-11-24 | Permissions | Use a passive event tap with Input Monitoring access and show the capture state in Settings and the HUD. | Permission changes can recover automatically. Secure input is surfaced explicitly. |
| 2026-11-24 | Idle estimates | Keep the learned pattern through pauses up to 30 seconds. After a longer pause, reset to the provisional 4/4 baseline. | Supersedes the three-second reset so short pauses preserve learning. |
| 2026-11-24 | Pulse tolerance and averaging | Average normalized tap intervals over a rolling 12 seconds with 20% timing tolerance. Show an average after ten seconds of tapping even when the pulse is uncertain. | Supersedes the strict 6% match and fixed interval count that could leave uneven tapping on Finding pulse. Clear rhythms can establish BPM earlier. |
| 2026-11-24 | Uncertain BPM | Prefix BPM with the approximate symbol below 0.70 confidence and retain the previous BPM through brief uncertainty. | An uncertain average remains visible. The existing 30-second idle reset still applies, and EQ feedback responds independently of tempo confidence. |
| 2026-11-24 | Meter history | Retain up to three minutes or 2,048 hits, with recent evidence weighted more strongly. | Longer tapping can refine the current hypothesis and eventually replace it. |
| 2026-11-24 | Meter confidence | Mark tentative 3/4 and 4/4 with the approximate symbol, and remove the symbol when confidence reaches 0.8. Use a small switching margin to keep close candidates stable. | Confidence reflects recurrence, accents, duration and separation between candidates. |
| 2026-11-24 | Accessibility | Use system appearance colors and glass, and honor Reduce Motion in custom pulse drawing. | The HUD follows macOS appearance preferences. |
| 2026-11-24 | Border preview | Include D/F joint hits in the existing rhythm preview and describe the combination in Settings. | The complete border effect can be checked without live keyboard capture. |
| 2026-11-24 | Packaging | Build a local ad-hoc signed app at `build/DrumKey.app`. | Developer ID signing and notarization are needed for public distribution. |
